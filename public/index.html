Irányítószámok REST API Dokumentáció

Laravel Sanctum alapú REST API megyék és települések kezelésére.

Base URL: http://127.0.0.1:8000/api

Hitelesítés (Auth)

POST/login

Felhasználó bejelentkeztetése és Bearer token generálása.

MezőTípusLeírás
emailStringRegisztrált email cím (pl. user@example.com)
passwordStringJelszó (pl. 12345678)
{ "user": { "id": 1, "name": "user", "email": "user@example.com" }, "token": "1|..." }
POST/logoutBearer Token szükséges

Aktív hozzáférési token érvénytelenítése.

{ "message": "Logged out" }

Megyék (Counties)

GET/counties

Összes megye listázása, opcionális név szerinti kereséssel.

Query paraméterTípusLeírás
search (opcionális)StringKeresés megye nevére
GET/counties/{id}

Egy adott megye és a hozzá tartozó települések lekérdezése.

POST/countiesBearer Token szükséges

Új megye létrehozása.

{ "name": "Pest" }
PUT/counties/{id}Bearer Token szükséges

Meglévő megye nevének módosítása.

{ "name": "Pest vármegye" }
DELETE/counties/{id}Bearer Token szükséges

Megye törlése azonosító alapján.

Települések (Cities)

GET/cities

Települések listázása, keresése és megye szerinti szűrése.

Query paraméterTípusLeírás
search (opcionális)StringKeresés irányítószámra vagy településnévre
county_id (opcionális)NumberSzűrés megye azonosítóra
GET/cities/{id}

Egy adott település részletes adatainak lekérdezése.

POST/citiesBearer Token szükséges

Új település létrehozása.

{ "zip": "2623", "name": "Kismaros", "county_id": 1 }
PUT/cities/{id}Bearer Token szükséges

Meglévő település adatainak módosítása.

{ "zip": "2623", "name": "Kismaros", "county_id": 1 }
DELETE/cities/{id}Bearer Token szükséges

Település törlése azonosító alapján.
